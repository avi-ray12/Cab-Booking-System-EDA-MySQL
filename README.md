# Cab-Booking-System 
This project simulates a real-world Cab Booking System to understand how structured databases support business operations. <br>
It covers the creation of a relational schema, populating realistic data, and running analytical SQL queries to extract insights into:<br>
- Customer behaviour<br>
- Driver performance<br>
- Trip patterns<br>
- Revenue trends<br>
- Service quality metrics<br>

The goal of this project is to demonstrate capability in database design, ETL, SQL analytics, and generating actionable business insights.

# 📊 End-to-End Workflow
**1. Database Schema Design<br>**
   Created and implemented a normalized 6-table relational schema:<br>
- Customers
- Drivers
- Cabs
- Bookings
- TripDetails
- Feedback

Used Primary Keys, Foreign Keys, and relationships to ensure data integrity.

**2. Data Insertion (ETL Simulation)** <br>
Inserted realistic and consistent datasets including: <br>
- Customer info
- Driver profiles
- Cab details
- Bookings and trip metrics
- Feedback and ratings

This simulated a real transactional database used by cab platforms.

**3. SQL Analytics – Insights Extraction** <br>
Wrote 10+ SQL queries to extract operational insights, including:<br>

✔ Customer Insights
- Total completed bookings per customer
- Customers with >20% cancellation rate
- Booking patterns by day of the week

✔ Driver Performance Insights
- Drivers with low feedback (<3.0)
- Top 5 drivers by distance travelled
- Drivers with >25% cancellation rate
- Driver earnings + performance summary

✔ Trip/Revenue Insights
- Monthly revenue trends
- Revenue by vehicle type
- Short-trip vs long-trip revenue
- Weekday vs weekend performance

Each query includes insights sections explaining business value and interpretation.
